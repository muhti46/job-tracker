# Job Tracker Chrome Extension

Save LinkedIn jobs, edit their details, and track your application status.

## Kurulum

1. Open `chrome://extensions` in Chrome.
2. Enable **Developer mode**.
3. Click **Load unpacked** and select this folder.
4. Open a LinkedIn job page and use the **Save job** button or the extension icon.

## Taslak kapsamı

- Capture the job title, company, location, work arrangement, salary, full description, and URL
- Store jobs in Chrome local storage
- Track Saved, Applied, Interview, Offer, and Rejected statuses
- Edit all job details and add personal notes on a full-page editor
- Delete jobs and filter by status

LinkedIn's page structure may change, so DOM selectors may need updates over time.
